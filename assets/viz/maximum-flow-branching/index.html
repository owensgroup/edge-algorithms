Maximum Flow (Push-Relabel)  ›  the sequential cascade, written from the pseudocode

Not derived from the parallel cascade — written the way you would write while there is an active vertex: pick one, then push or relabel. The test is taken once, before anything is written, so every round is exactly one operation: 29 rounds, 29 operations, the same 29 the textbook performs, in the same order. The other sequential cascade keeps the parallel Einsum list and gates it with a selector — that evaluates both arms every round and lets emptiness mask one out, which packs those 29 operations into 26 rounds. Steps marked changed are where the two differ.
